📊 DATA STRUCTURE:

User:
  • userId, totalXP (2450), level (7)
  • claimedSBTs: [{ HTML Basics, Python Logic }]
  • activeSBT: { Full-Stack Path, progress: 43% }
  • dailyBounty: { +150 XP, not claimed }

House:
  • 6 houses total (1 completed, 1 active, 4 locked)
  • Each house has 4 stages
  • Stages: Material, Quiz, Lab, Project
  • Status: completed | active | locked
  • Progress: 0-100%

CareerTrack:
  • 9 tracks total
  • Categories: Web, Mobile, AI, Blockchain, etc.
  • Difficulty: beginner | intermediate | advanced
  • Estimated weeks: 10-20
  • Tech tags: 2-4 per track
